# cadastro-alunos-python
# Sistema de Gestão de Alunos (CRUD em Python + SQLite)

Aplicação interativa em linha de comando (CLI) desenvolvida em Python para gerenciar o cadastro de alunos e seus respetivos cursos, utilizando **SQLite** para persistência de dados relacional.

## Funcionalidades (CRUD)

- **Create (Cadastrar):** Inserção de novos alunos no banco de dados.
- **Read (Listar/Buscar):** Consulta de todos os alunos cadastrados e busca por nome utilizando `LIKE`.
- **Update (Atualizar):** Edição de informações existentes via chave primária (`ID`).
- **Delete (Deletar):** Remoção de registos do banco de dados por `ID`.

## Tecnologias Utilizadas

- **Python**
- **SQLite3** (Banco de dados relacional)
- **VS Code** (IDE)
